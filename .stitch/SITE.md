# Village Connect

## 1. Core Identity
- **Project Name**: Village Connect (Towncare)
- **Stitch Project ID**: 7443330577422698844
- **Mission**: Local Worker & Service Finder that connects customers with workers for various services.
- **Target Audience**: Local community members looking for services and workers looking for jobs.
- **Voice**: Trustworthy, professional, friendly, and accessible.

## 2. Visual Language
- **Vibe (Adjectives)**: Clean, approachable, reliable.

## 3. Architecture & File Structure
- **Navigation Strategy**: Bottom navigation bar for main user flows (Home, Bookings, Chat, Profile). Separate flows for Customer, Worker, and Admin.
